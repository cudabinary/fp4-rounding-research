Question and fixed contract

Let x and a be finite BF16 magnitudes with 0 <= x <= a. The group scale is
s = RN32(a/6), with gradual underflow and zero-group fallback 2^-42.
The E2M1 magnitude grid remains {0, 1/2, 1, 3/2, 2, 3, 4, 6}.
Only the quotient's working significand precision p and the probability lattice
width b are varied. Working exponent range remains binary64's. This is scalar
threshold arithmetic, not a new RNG policy, CUDA program or model experiment.

On an exact nonsaturated interval of width Delta = 1/2, 1, or 2, set
S = b - log2(Delta). The central identity is

 floor(2^S * RN_p(x/s)) = floor(2^S * (x/s)).

The common lower-endpoint integer offset is then subtracted. Subtraction and
power-of-two interval scaling are exact here: the nonzero intervals satisfy
Sterbenz's ratio condition, and the zero-endpoint case is direct. Saturation
and exact boundaries must still be composed with the canonical base selector.
The direct validator executes that complete selector/interpolation numerically.

1. Roux 2014, Theorem 29, printed page 140 / PDF page 10

Primary publisher PDF was retrieved and hashed. Its Theorem 29 is for even
radix, operands in FLX_p1, both roundings to nearest, and p2 >= 2*p1.

Direct substitution p1=24, p2=53 is valid for BF16-expanded x and F32 s as
24-bit operands, in the no-intermediate-underflow setting. What follows is
nearest-rounded binary24 division equivalence, NOT the b=32 threshold floor.

Substitution p1=2 based on FP4's value precision is invalid: neither operand
membership nor the probability lattice is represented by that choice.

A floating target fine enough for the b=32 upper-binade lattice needs up to
b+2 = 34 significant bits. Padding the operands into FLX_34 would still leave
53 < 2*34, and the named theorem's final mode is nearest rather than floor.
Thus this is not a direct instantiation of that named theorem.

Roux's introduction also discusses mixed nearest/directed extensions. We did
not execute the Coq developments or exhaust every generic-format lemma.
Failure of this direct substitution does NOT prove independence from Roux's
entire theory, the Flocq library, or another separation lemma.

2. Saiki et al. 2026, arXiv:2610.09005v1, sections 5.2 and 6

The pinned v1 HTML was retrieved and hashed. Figure 8 lists safe uniform mode
chains: RTZ->RTZ, RAZ->RAZ, RTO->RTO, and RTO->RTZ/RAZ/RNE with padding.
Table 2 supplies counterexamples for the other mode chains, including the
current RNE intermediate followed by RTZ/floor, over unrestricted reals.

Therefore plain format containment alone does not justify deleting the
current RN53 before a fixed-lattice floor. Replacing RN53 with RTO would
change the written reference contract and does not establish equality with
the existing RN53 result without an additional argument.

The proposed semantic rewrite methodology and format inference are existing
work. The quotient here is generally non-dyadic, so the rule that removes a
rounding because its exact input is already representable cannot simply be
applied to x/s. The missing side condition is exclusion of the narrow
preimages of upward lattice crossings, using actual operand relationships.
Existing generic frameworks may encode such a side condition once supplied;
this round does not establish a new verification framework.

What is already standard and what remains additional

Standard: representability of lattice boundaries, exact dyadic interpolation,
integer quotient/remainder analysis, the half-ULP crossing test, power-of-two
exponent normalization, exhaustive finite checking, and counterexample search.

For r=n/d, E=floor(log2(r)), rem=(n*2^S) mod d and j=d-rem>0,
the familiar crossing condition in the tested p>=b+3 region is

 j * 2^(p-E-S) <= d.

All relevant lattice boundaries are exactly representable with an even last
bit in that region. Equality therefore rounds upward to the lattice boundary.
This is an existing rounding/separation argument, not a new general theorem.

The additional domain work is to prove that the actual BF16-derived divisors
exclude this condition at the desired (b,p), or to expose the first legal
counterexample when it ceases to hold. The new finite boundary data addresses
that side condition; it does not by itself establish publication novelty.
